# 03 — 语言体系

> 界面语言、内容语言、自定义语言三套并存但统一治理。

---

## 1. 三类语言的概念区分（必须先分清）

| 维度 | 界面语言 (UI Locale) | 内容语言 (Content Language) | 自定义语言 (Custom Locale) |
|---|---|---|---|
| **控制什么** | UI 文案、组件文案、日期/数字格式、排序规则、方向(LTR/RTL) | 论文摘要、PPT 文字、问答回答、生成内容 | 与界面语言同机制，只是文案表由用户/机构提供 |
| **取值** | 12 种内置 + 任意自定义 | 20 种内置 + 任意自定义 | 同界面语言 |
| **谁选** | 用户偏好 / URL / 浏览器 | 生成时按内容源或显式指定 | 用户/机构 |
| **存储位置** | `localStorage` + `Accept-Language` | 请求参数 / 项目设置 | 服务端 `branding` 配置 |
| **示例** | `zh-CN` | `zh` | `zh-CN` + 机构自定义词条 |

**关键原则**：界面语言与内容语言**完全解耦**。用户用中文界面，但可以生成英文 PPT。

```
用户界面 = zh-CN
论文是英文 → 摘要默认 en
用户想做法语汇报 → PPT 内容语言 = fr
         ↑ 三者互不影响
```

## 2. 界面语言（UI Locale）

### 2.1 内置 12 种

| Code | 名称 | RTL | AntD locale | 优先级 |
|---|---|---|---|---|
| `zh-CN` | 简体中文 | | `zh_CN` | L1 必做 |
| `en-US` | English | | `en_US` | L1 必做 |
| `zh-TW` | 繁體中文 | | `zh_TW` | L2 |
| `zh-HK` | 繁體中文（香港） | | `zh_HK` | L2 |
| `ja-JP` | 日本語 | | `ja_JP` | L2 |
| `ko-KR` | 한국어 | | `ko_KR` | L2 |
| `fr-FR` | Français | | `fr_FR` | L2 |
| `de-DE` | Deutsch | | `de_DE` | L2 |
| `es-ES` | Español | | `es_ES` | L2 |
| `pt-BR` | Português (Brasil) | | `pt_BR` | L2 |
| `ru-RU` | Русский | | `ru_RU` | L2 |
| `ar-EG` | العربية | ✅ RTL | `ar_EG` | L2（RTL 验证） |

**L1/L2 定义**：
- **L1 核心**（`zh-CN` / `en-US`）：平台维护，**100% 覆盖**，CI 强制
- **L2 扩展**（其余 10 种）：平台提供骨架 + 社区/运营补全，**≥80% 覆盖**
- **L3 自定义**：任意 locale，运行时注册

**为什么选这 12 种**：覆盖全球科研产出 TOP 语言 + 华人圈三地 + 一个 RTL 验证实现。

### 2.2 语言注册表

```ts
// packages/ui/src/i18n/locales.ts
import zhCN from 'antd/locale/zh_CN';
import enUS from 'antd/locale/en_US';
// …

export interface LocaleDefinition {
  /** BCP 47 语言标签 */
  code: string;
  /** 母语名称（不翻译，永远用该语言自身显示）*/
  label: string;
  /** 书写方向 */
  dir: 'ltr' | 'rtl';
  /** AntD 内置 locale（用于组件文案）*/
  antd?: Locale;
  /** 数字/日期/货币格式 */
  formats?: Intl.NumberFormatOptions;
  /** 是否为平台内置（L1/L2）*/
  builtin: boolean;
}

export const LOCALES: Record<string, LocaleDefinition> = {
  'zh-CN': { code: 'zh-CN', label: '简体中文', dir: 'ltr', antd: zhCN, builtin: true },
  'en-US': { code: 'en-US', label: 'English', dir: 'ltr', antd: enUS, builtin: true },
  'ar-EG': { code: 'ar-EG', label: 'العربية', dir: 'rtl', antd: arEG, builtin: true },
  // …
};
```

### 2.3 文案回退链（5 级）

```
① overrides[key]              运行时覆盖（最高优先级）
② locales[locale][key]        运行时注册的语言表（自定义语言）
③ BUILTIN[locale][key]        平台内置（12 种）
④ BUILTIN['en-US'][key]       内置英文兜底
⑤ key 本身                    永不 undefined
```

**为什么第 4 级兜底英文而不是中文**：
一个没配置全的语言，用中文兜底会"中英混杂"，更糟。用英文兜底至少是**一致的一种语言**。

> ⚠️ 此设计源自 `scholar-pdf-viewer` 的 `resolveMessage()`（已验证），本项目在其基础上**增加命名空间与类型安全**。

### 2.4 自定义语言（运行时注册）

```tsx
// 场景 A：用户注册一种新语言（仅当前会话/本地）
<I18nProvider
  locale="tlh"
  messages={{
    tlh: {
      'common.action.confirm': 'yImej',
      'paper.search.placeholder': 'rIv searching',
      // 缺失的自动回退到 en-US
    },
  }}
>
```

```tsx
// 场景 B：机构级品牌语言（服务端下发，全租户生效）
// GET /api/v1/config/branding → { locale: 'xx-XX', messages: { 'xx-XX': {...} } }
```

**自定义语言的能力边界**：
| 能做 | 不能做 |
|---|---|
| 覆盖任意文案 key | 改变 AntD 组件内部文案（除非 AntD 有对应 locale）|
| 新增任意 locale | 新增未注册的方向（只能 ltr/rtl）|
| 运行时热切换 | 动态改变数字/货币格式（需 locale 定义支持）|

### 2.5 文案 Key 命名规范（强制）

```
格式：  <domain>.<section>.<element>[.<state>]
```

| 段 | 含义 | 规则 |
|---|---|---|
| `domain` | 业务域 | `auth` `paper` `slides` `orchestra` `community` `billing` `common` `pdf` |
| `section` | 页面/区块 | camelCase |
| `element` | 元素 | camelCase |
| `state` | 状态 | **白名单**：`error` `loading` `empty` `success` `hint` `tooltip` `label` |

**示例**：
```
common.action.confirm
common.error.network
auth.login.title
auth.login.form.password
auth.login.error.invalid
paper.search.placeholder
paper.search.result.count          → "共 {count} 条"
paper.filter.range.startYear
slides.editor.button.export
slides.editor.status.rendering
community.post.action.repost
pdf.viewer.zoom.fitWidth
```

**规则**：
- 全小写，段用 `.` 分隔，段内 camelCase
- 占位符统一 `{name}`（不用 `%s`、不用 `{{}}`、不用 `<<>>`）
- **禁止**在代码里写死用户可见文案 → CI 门禁扫描
- key 一经发布**不可重命名**（只能废弃）→ 废弃用 `common.deprecated.<key>`

### 2.6 命名空间与类型安全

每个包导出自己的命名空间：

```
packages/paper/src/i18n/{zh-CN,en-US}.ts   → 'paper.*'
packages/slides/src/i18n/{zh-CN,en-US}.ts  → 'slides.*'
```

主站启动时合并成完整表：

```ts
// packages/ui/src/i18n/messages/index.ts
export type MessageKey =
  | keyof typeof COMMON
  | keyof typeof PAPER
  | keyof typeof SLIDES
  | …;

export const MESSAGES: Record<string, Partial<Record<MessageKey, string>>> = {
  ...COMMON, ...PAPER, ...SLIDES, …
};
```

**收益**：缺少 key → **编译期报错**，不是运行时才发现。

### 2.7 CI 校验规则

```bash
# ① key 命名规范
#    正则：^(auth|paper|slides|orchestra|community|billing|pdf|common)\.[a-zA-Z]+(\.[a-zA-Z]+)*$
# ② L1 覆盖一致性：zh-CN 与 en-US 的 key 集合必须完全相同
# ③ L2 覆盖率：非 L1 语言 ≥80%
# ④ 占位符一致性：同一 key 在不同语言的占位符集合必须相同
#    （en: "共 {count} 条"  vs  ja: "合計 {count} 件"  ✅
#      en: "共 {count} 条"  vs  ja: "合計 件"      ❌ 报错）
# ⑤ 禁止硬编码文案：扫描 JSX 文本节点与字符串字面量
```

## 3. 内容语言（Content Language）

### 3.1 内置 20 种

比界面语言更广，因为**论文与演示内容**面向全球学术读者。

| Code | 名称 | Code | 名称 |
|---|---|---|---|
| `zh` | 中文 | `ko` | 한국어 |
| `en` | English | `th` | ไทย |
| `ja` | 日本語 | `vi` | Tiếng Việt |
| `fr` | Français | `id` | Bahasa Indonesia |
| `de` | Deutsch | `ms` | Bahasa Melayu |
| `es` | Español | `ar` | العربية |
| `pt` | Português | `hi` | हिन्दी |
| `ru` | Русский | `fa` | فارسی |
| `it` | Italiano | | |

**+ `auto`**：自动检测（跟随论文原文语言）

### 3.2 使用场景

| 场景 | 参数 | 默认 |
|---|---|---|
| 论文结构化摘要 | `lang=zh\|en`（现有 `papersketch?lang=`）| `auto`（检测原文）|
| 论文问答回答 | `lang` | `auto` |
| 术语解释 | `lang` | 跟随问答语言 |
| PPT 文字 | `outputLanguage` | 用户在生成时选 |
| 论文翻译 | `targetLang` | 显式指定 |
| 社区帖子 | `lang` | `auto` |

### 3.3 实现：提示词注入

沿用 `scholarclub-ppt-service` 的 `LANGUAGE_CONFIG` 模式（精华移植）：

```python
# packages/llm/src/llm/locales.py
LANGUAGE_CONFIG: dict[str, LanguageSpec] = {
    "zh": LanguageSpec(name="中文",
                       instruction="请使用全中文输出。",
                       ppt_text="PPT文字请使用全中文。"),
    "en": LanguageSpec(name="English",
                       instruction="Please output all in English.",
                       ppt_text="Use English for PPT text."),
    "ja": LanguageSpec(name="日本語",
                       instruction="すべて日本語で出力してください。",
                       ppt_text="PPTのテキストは全て日本語で出力してください。"),
    # … 20 种
    "auto": LanguageSpec(name="自动", instruction="", ppt_text=""),
}
```

**改进点**：
- 原版只 4 种 → 扩展到 20 种 + `auto`
- 原版 `LANGUAGE_CONFIG` 硬编码在 service 里 → 移到 `llm` 包（所有包共用）
- 提示词由 `llm` 包统一注入，业务代码不写语言指令

### 3.4 `auto` 检测

```python
async def detect_content_language(text: str) -> str:
    """检测论文原文语言 → 返回 BCP 47 主语言码"""
    # ① 启发式：字符集统计（中日韩统一表意文字 / 假名 / 谚文 / 西里尔 / 阿拉伯 / 拉丁）
    # ② 置信度 < 0.8 → 回退 'en'
```

**不依赖外部服务**（避免额外成本与延迟）。

## 4. 界面语言 vs 内容语言：为什么必须解耦

| 场景 | UI | 内容 | 说明 |
|---|---|---|---|
| 中国研究生读英文论文 | `zh-CN` | `en` | 界面中文，摘要英文 |
| 该生要组会汇报 | `zh-CN` | `zh` | 界面中文，PPT 中文 |
| 该生要投国际会议 | `zh-CN` | `en` | 同一界面，PPT 切英文 |
| 日本用户 | `ja-JP` | `en` | 界面日文，论文英文 |

**实现方式**：
```tsx
// 界面语言 → 上下文全局
<I18nProvider locale={uiLocale}>        // React Context
// 内容语言 → 显式参数，逐次请求
await fetchSummary({ fileMd5, lang: 'en' })
await createSlideProject({ outputLanguage: 'ja' })
```

**绝不能**用界面语言隐式决定内容语言（会强制用户为看英文论文切英文界面）。

## 5. RTL 支持

架构预留（不实现全部翻译，但保证不崩）：

| 层面 | 处理 |
|---|---|
| `dir` 属性 | `<html dir="rtl">` 由 `LocaleDefinition.dir` 驱动 |
| AntD | 用 `ar_EG` locale，AntD 内建 RTL 样式 |
| Tailwind | 启用 `logical properties`（`ms-`/`me-`/`ps-`/`pe-` 替代 `ml-`/`mr-`/`pl-`/`pr-`）|
| 图标方向 | 方向性图标（箭头）需镜像 → 统一在 `ui/icons` 层处理 |
| 数字/日期 | `Intl` API 自动处理 |
| 排版引擎 | `slides` 的文本量测需支持 RTL（`generate_poster_pil` 的按字宽估算需改）|

## 6. 语言包格式与分发

### 6.1 格式：JSON（扁平 key）

```json
{
  "common.action.confirm": "确定",
  "common.action.cancel": "取消",
  "paper.search.placeholder": "搜索论文、作者或关键词"
}
```

**为什么扁平 JSON 而不是嵌套**：
- 扁平 key 可直接做正则校验、缺失检测、覆盖率计算
- 嵌套在 key 拼接时容易产生不一致的路径

### 6.2 分发

```
内置语言  → 随包发布（BUILTIN）
L2 扩展   → 平台维护（packages/ui/src/i18n/messages/）
自定义    → 运行时 JSON / API 下发
```

**运行时加载接口**：
```http
GET /api/v1/i18n/locales/{locale}
→ { "locale": "tlh", "messages": { ... }, "coverage": 0.42 }
```
