# 01 — 精华与糟粕

> 参考项目只作"素材库"。逐条判定"留"与"弃"，避免把旧问题带进新系统。

---

## 0. 判定原则

| 原则 | 说明 |
|---|---|
| **只借鉴，不复制** | 不拷贝源码。抄架构思路、算法、数据结构、API 形状 |
| **抄结构不抄实现** | 例如抄 Mastodon 的 `statuses` 表字段设计，不抄 Rails 模型 |
| **抄算法不抄耦合** | 例如抄 `generate_poster_pil` 的文本量测算法，不抄它的全局状态与硬编码字体 |
| **抄产品不抄技术债** | 例如抄 ScholarClaw 的 EventBus 事件契约，不抄 Bun 技术栈 |
| **License 门禁** | CI 扫描，AGPL/MIT 混用直接失败 |
