## 1. 决策：AntD 基座 + 自研层

### 1.1 为什么不全自研组件库

| 成本项 | 人天 |
|---|---|
| 基础组件（70+ 个）| 200-350 |
| 无障碍（键盘/焦点/ARIA/屏幕阅读器）| 150+ |
| 虚拟滚动与性能 | 60+ |
| 暗色 / 紧凑 / 多密度算法 | 20 |
| 70 种语言 locale | 70 |
| 焦点管理与层叠（Modal/Drawer/Popover 嵌套）| 40 |
| 动画一致性 | 20 |
| **合计** | **≈ 500-600 人天 ≈ 2.5-3 人年** |

对比：团队 2 人 / 总工期 24 周 / 13 个子项目并行。
**自研组件库会吃掉 1/3 预算且零业务价值。**

## 2. 品牌主题

### 2.1 BrandConfig

```ts
// packages/ui/src/theme/brand.ts
export interface BrandConfig {
  /** 品牌主色（→ AntD token.colorPrimary）*/
  colorPrimary: string;

  /** 语义色覆盖（不传则用 AntD 默认派生）*/
  colors?: {
    success?: string;
    warning?: string;
    error?: string;
    info?: string;
  };

  /** 圆角基准（→ token.borderRadius + 组件级结构）*/
  borderRadius?: number;

  /** 字体族（→ token.fontFamily）*/
  fontFamily?: string;

  /** 布局密度 → 决定 algorithm 组合 */
  density?: 'default' | 'compact';

  /** 主题模式 */
  mode?: 'light' | 'dark' | 'auto';

  /** 品牌展示 */
  brandName?: string;
  logo?: { light: string; dark: string };
  favicon?: string;
}
```

### 2.2 配置来源（5 级，优先级高→低）

| 级 | 来源 | 场景 | 持久化 |
|---|---|---|---|
| ① | `/api/v1/config/branding` 响应 | 机构/租户级品牌 | 服务端 |
| ② | URL 参数 `?brandColor=…&theme=…` | 预览 / 嵌入 / 分享 | 无 |
| ③ | `localStorage` | 用户个人偏好 | 浏览器 |
| ④ | 构建期 `VITE_BRAND_*` | 多租户镜像 | 编译时 |
| ⑤ | 内置预设 | 默认 | 代码 |

**解析优先级链**：
```ts
const brand = mergeBrands(
  DEFAULT_BRAND,          // ⑤
  envBrand,               // ④
  storageBrand,           // ③
  urlBrand,               // ②
  apiBrand,               // ①
);
```
> 注意：**① 优先级最高**（服务端权威），但"用户个人偏好"③ 应该能覆盖机构默认 ① —— 这是产品决策，需明确。**建议**：主题模式（明/暗/紧凑）由用户控制，品牌色由机构控制，二者分离。

### 2.4 ThemeProvider 实现

```tsx
// packages/ui/src/theme/provider.tsx
export function ScholarThemeProvider({
  brand,
  locale,
  children,
}: {
  brand: BrandConfig;
  locale: LocaleDefinition;
  children: React.ReactNode;
}) {
  const systemDark = useSystemPrefersDark();
  const isDark = brand.mode === 'dark' || (brand.mode === 'auto' && systemDark);

  const antdTheme = useMemo<ThemeConfig>(
    () => ({
      // ① 算法：暗色 + 可选紧凑（可组合）
      algorithm: [
        isDark ? theme.darkAlgorithm : theme.defaultAlgorithm,
        ...(brand.density === 'compact' ? [theme.compactAlgorithm] : []),
      ],

      // ② 种子令牌：只设品牌相关，AntD 自动派生全部状态色
      token: {
        colorPrimary: brand.colorPrimary,
        colorInfo: brand.colors?.info,
        colorSuccess: brand.colors?.success,
        colorWarning: brand.colors?.warning,
        colorError: brand.colors?.error,
        colorLink: brand.colorPrimary,
        colorLinkHover: brand.colorPrimary,   // AntD 自动派生 hover/active
        borderRadius: brand.borderRadius ?? 6,
        fontFamily: brand.fontFamily,

        // 全站统一的设计基准
        fontSize: 14,
        sizeUnit: 4,
        sizeStep: 4,
        motionUnit: 0.1,
        motionBase: 0,
        wireframe: false,
      },

      // ③ 组件级：只调"结构"，绝不调"颜色"
      components: {
        Button: { controlHeight: 36, fontWeight: 500, borderRadius: brand.borderRadius ?? 6 },
        Input:  { controlHeight: 36, borderRadius: brand.borderRadius ?? 6 },
        Select: { controlHeight: 36 },
        Card:   { borderRadiusLG: 12 },
        Table:  { headerBg: 'transparent', cellPaddingBlockSM: 8 },
        Layout: { headerHeight: 56, bodyBg: 'transparent' },
        Tabs:   { horizontalItemGutter: 24 },
      },
    }),
    [brand, isDark],
  );

  return (
    <ConfigProvider
      theme={antdTheme}
      locale={locale.antd}
      direction={locale.dir}
    >
      {children}
    </ConfigProvider>
  );
}
```

### 2.5 关键规则：组件级不写颜色

**现状问题**（`constants/theme.ts`）：
```ts
Button: {
  colorPrimary: '#611F6A',       // ❌ 手写
  colorPrimaryHover: '#723678',  // ❌ 手写
  colorPrimaryActive: '#3D1145', // ❌ 手写
  colorPrimaryBorder: '#611F6A', // ❌ 手写
  colorText: '#611F6A',          // ❌ 手写
  // …共 12 处
}
```
换主色要改 20 处，还容易漏。

**正确做法**：
```ts
token: { colorPrimary: brand.colorPrimary }   // ✅ 一处
// AntD 自动派生 primary1..10 / bg / border / hover / active / text
```

**CI 门禁**：
```bash
# 组件级不得出现颜色字面量
grep -rnE "color[A-Za-z]*:\s*['\"]#|color[A-Za-z]*:\s*['\"]rgb" \
  packages/ui/src/theme/  | grep -v "presets.ts"    # ❌ 失败
```

### 2.6 明暗模式

| 模式 | 行为 |
|---|---|
| `light` | 固定亮色 |
| `dark` | 固定暗色 |
| `auto` | 跟随系统（`prefers-color-scheme`）|

**持久化**：用户选择存 `localStorage`，**优先于**机构默认。
**跨标签同步**：监听 `storage` 事件。

## 3. 样式系统

### 3.1 三者职责

| 系统 | 职责 | 禁止 |
|---|---|---|
| **AntD v5** | 所有组件（Button/Table/Modal/Form…）| — |
| **Tailwind v4** | **仅布局与间距**（flex/grid/gap/padding/margin/响应式）| ❌ 颜色、字号、阴影、圆角 |
| **CSS 变量** | 跨系统传值、给非 React 消费方 | ❌ 硬编码颜色 |

### 3.2 Tailwind 允许的类（白名单）

```
布局：flex grid block inline hidden relative absolute fixed sticky
      container mx-auto
间距：p-* m-* px-* py-* gap-* space-*  （限 spacing scale）
尺寸：w-* h-* min-w-* max-w-* min-h-* max-h-*  （限 spacing scale）
文本对齐：text-left text-center text-right
溢出：overflow-* truncate
定位偏移：top-* left-* right-* bottom-* inset-*
显示：flex inline-grid
响应式：sm: md: lg: xl: 2xl:
```

### 3.3 Tailwind 禁止的类（黑名单，CI 门禁）

```bash
# 颜色
grep -rnE "class(Name)?=[\"'][^\"']*\b(text|bg|border|ring|fill|stroke|from|to|via)-(slate|gray|zinc|neutral|stone|red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose)-[0-9]{2,3}" apps/ packages/

# 字号 / 字重 / 阴影 / 圆角
grep -rnE "class(Name)?=[\"'][^\"']*\b(text-(xs|sm|base|lg|xl|[2-9]xl)|font-(thin|light|normal|medium|semibold|bold)|shadow-(sm|md|lg|xl|2xl)|rounded-(sm|md|lg|xl|2xl|3xl|full))\b" apps/ packages/
```

> 颜色与字号必须走 AntD token → 保证换主题/暗色/品牌色全站生效。

### 3.4 styled-components 全面移除

39 处全部移除。替代方案：

| 原用法 | 替代 |
|---|---|
| `styled.div\`...\`` 布局 | Tailwind 类 |
| `styled.div\`color: ...\`` | `style={{ color: 'var(--ss-color-xxx)' }}` 或 AntD token 类 |
| `keyframes` 动画 | Tailwind `animate-*` 或 CSS 文件 |
| `createGlobalStyle` | `styles/globals.css` |

CI 门禁：
```bash
grep -rn "styled-components" apps/ packages/   # ❌ 失败
```

## 4. 复合组件（自研层）

AntD 没有、但平台需要的：

| 组件 | 作用 | 关键点 |
|---|---|---|
| `PageHeader` | 统一页面头 | 标题/描述/面包屑/操作区/返回 |
| `EmptyState` | 统一空态 | 图标/标题/描述/引导操作（可插图表）|

| `FormField` | 表单项 | label/错误/提示/必填标记统一 |
| `DataTable` | 数据表格 | TanStack Table v8 + AntD 外观 + 虚拟滚动 |
| `SearchInput` | 搜索框 | 历史/快捷键/示例/防抖 |
| `RichTextEditor` | 富文本 | Tiptap + AntD 风格（替代 react-quill）|
| `FileDrop` | 文件拖拽 | 校验/进度/预览/取消（替代 antd-img-crop 配套）|
| `AvatarCropper` | 头像裁剪 | react-easy-crop + AntD Upload（替代 antd-img-crop）|
