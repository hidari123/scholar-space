# 布局体系 —— 需要统一的所有布局形态

> ⚠️ **目的**：把「所有站长得一样」这件事，从口号变成可执行的清单。
>
> ⚠️ **判断标准**：**同一个东西在 A 站和 B 站必须长得一样**。
> 一样的 → 进 `@scholarspace/ui`；不一样的 → 各站自己写。

---

## 一、总览：14 类布局

| # | 布局 | 用在哪 | 层级 |
|---|---|---|---|
| **L1** | 应用外壳 `SiteShell` | 每站最外层 | ui |
| **L2** | 页面骨架 `PageFrame` | 每个页面 | ui |
| **L3** | 三栏工作区 `WorkspaceLayout` | 列表+详情类页面 | ui |
| **L4** | 主从分栏 `SplitLayout` | 目录+内容类 | ui |
| **L5** | 看板 `KanbanLayout` | 流程/运行状态 | ui |
| **L6** | 画布 `CanvasWorkspace` | 编排/幻灯片 | ui |
| **L7** | 文档流 `DocumentFlow` | 论文详情/全文 | ui |
| **L8** | 表单页 `FormPage` | 设置/新建 | ui |
| **L9** | 搜索结果 `SearchResults` | 论文库 | ui |
| **L10** | 抽屉 `DetailDrawer` | 详情面板 | ui |
| **L11** | 弹窗 `ModalDialog` | 新建/确认 | ui |

| **L13** | 空/错/载入 `StateView` | 所有异步区 | ui |
| **L14** | 反馈 `FeedbackLayer` | 通知/进度 | ui |

## 二、L1 · 应用外壳 `SiteShell`

```
┌──────────────────────────────────────────────────────┐
│ SiteHeader                          56px            │
├────────┬─────────────────────────────────────────────┤
│        │                                             │
│ Sidebar│  Content                                    │
│ 200px  │  flex: 1                                   │
│        │                                             │
├────────┴─────────────────────────────────────────────┤
│ SiteFooter                          48px            │
└──────────────────────────────────────────────────────┘
```

### 要统一的点

| 项 | 规格 |
|---|---|
| Header 高度 | 56px |
| Sidebar 宽度 | 200px（可折叠到 64px 只留图标）|
| Footer 高度 | 48px |
| 内容区内边距 | 24px（紧凑模式 16px）|
| Sidebar 折叠状态 | 记忆到 localStorage |
| Sidebar 可折叠 | 桌面端可移动端不显示 |

### `SiteHeader` 的插槽结构

```
┌──────────────────────────────────────────────────────┐
│ [Logo/站名]  [站内导航 slot]   [全局搜索 slot]  [操作 slot] [用户 slot] │
└──────────────────────────────────────────────────────┘
```

⚠️ **「站内导航」和「站点间导航」是两回事**：
- 站内导航 —— 当前站的页面（如论文库的「检索/导入」）
- 站点间导航 —— 跳到其他站（各站都有，指向同一套清单）

### `SiteFooter` 的内容

```
[版权] [版本号] [语言切换] [主题切换] [文档链接] [状态]
```

## 三、L2 · 页面骨架 `PageFrame`

⚠️ **每个页面的顶部结构必须一样** —— 现在主仓的 `PageHeader` 就是雏形，要搬进 ui 包并强化。

```
┌──────────────────────────────────────────────────────┐
│ PageTitle            [PageActions]                   │
│ PageDescription                                       │
│ ────────────────────────────────────────────────────  │
│ PageToolbar        （筛选区 / Tab / 批量操作）        │
│ ────────────────────────────────────────────────────  │
│ PageContent                                          │
└──────────────────────────────────────────────────────┘
```

### 规格

| 项 | 规格 |
|---|---|
| 标题字号 | `Title level={2}` |
| 描述 | `Text type="secondary"`，紧跟标题 |
| 标题与描述间距 | 0（同一个 `Space direction="vertical" size={0}`）|
| 操作区右对齐 | 与标题同一行的右侧 |
| 分隔线 | 仅当有 toolbar 时才画 |

⚠️ **「标题与操作区同一行」是硬规定** —— 否则每页的视觉重心会飘。

## 四、L3 · 三栏工作区 `WorkspaceLayout`

⚠️ **这是最常用的布局** —— 论文库、演示文稿列表、编排的流程列表都用它。

```
┌──────────┬───────────────────────────┬──────────────┐
│ Filters  │  List                     │  Detail      │
│ 240px    │  flex: 1                  │  400px       │
│          │                           │              │
│ 可折叠    │  卡片/表格                 │  可关闭      │
└──────────┴───────────────────────────┴──────────────┘
```

### 规格

| 项 | 规格 |
|---|---|
| 左栏宽度 | 240px（筛选区）/ 280px（目录区）|
| 右栏宽度 | 400px（摘要）/ 480px（完整信息）|
| 右栏行为 | 打开时中栏变窄，关闭时中栏全宽（**不是覆盖**）|
| 断点 | < 1200px → 右栏变覆盖层；< 768px → 只剩中栏 |
| 空态 | 中栏空、右栏空、左栏空，三处各自独立 |

⚠️ **右栏关闭后中栏要「长大」** —— 这是「不跳页」的关键。

---

## 五、L4 · 主从分栏 `SplitLayout`

⚠️ **和 L3 的区别**：右栏是「另一个实体」，不是「选中项的详情」。

```
┌────────────────┬───────────────────────────────────┐
│ Master         │ Detail                            │
│ 320px          │ flex: 1                           │
│                │                                   │
│ 树/列表         │ 独立的页面级内容                   │
└────────────────┴───────────────────────────────────┘
```

### 用在哪

- 论文库 → 左侧文献列表，右侧全文阅读
- 编排 → 左侧流程树，右侧流程详情
- 社区 → 左侧导航/关注列表，右侧时间线

### 和 L3 的区别（重要）

| | L3 三栏 | L4 主从 |
|---|---|---|
| 中栏 | 列表（可多选） | 无（直接是详情） |
| 右栏 | 选中项的详情 | 独立实体 |
| 中栏可折叠 | ❌ | ✅ |
| 打开右栏时 | 中栏保持可见 | 中栏消失 |

## 七、L6 · 画布 `CanvasWorkspace`

⚠️ **两个不同的画布，要分开**

### L6a · 幻灯片画布（slides）

```
┌──────────┬─────────────────────────────────────────┐
│ 页面列表  │  ┌─────────┐ ┌─────────┐ ┌─────────┐    │
│ 第1页     │  │ 幻灯片   │ │ 幻灯片   │ │ 幻灯片   │    │
│ 第2页     │  │  缩略图   │ │  缩略图   │ │  缩略图   │    │
│ 第3页     │  └─────────┘ └─────────┘ └─────────┘    │
│          │  ───────────────────────────────────    │
│          │  选中页的详情（要点/版式/降级警告）         │
└──────────┴─────────────────────────────────────────┘
```

### L6b · 节点画布（orchestra）

```
┌──────────┬─────────────────────────────────────────┐
│ 流程树    │   ┌────┐        ┌────┐                │
│          │   │节点 │───────▶│节点 │                │
│          │   └────┘        └────┘                │
│          │        │                                │
│          │        ▼                                │
│          │   ┌────┐                               │
│          │   │节点 │                               │
│          │   └────┘                               │
└──────────┴─────────────────────────────────────────┘
```

### 规格
- 画布区：可平移、可缩放
- 网格背景（点阵）
- 缩放控件：右下角固定
- 选中态：明显的描边
- ⚠️ **画布尺寸自适应容器**，不写死像素

## 九、L8 · 表单页 `FormPage`

⚠️ **两种表单要区分** —— 这也是常见的做错的地方。

### L8a · 模态表单（新建项目/导入）

```
┌────────────────────────────────┐
│ 新建演示文稿              [×]  │
├────────────────────────────────┤
│ 标题 *                          │
│ [___________________________]   │
│                                │
│ 来源类型                        │
│ [论文      ▾]                  │
│                                │
│ 主题                            │
│ [学术紫    ▾]                  │
├────────────────────────────────┤
│              [取消]  [创建]     │
└────────────────────────────────┘
```

### L8b · 独立表单页（设置/向导）

```
┌──────────────────────────────────────────────────────┐
│ PageTitle (PageFrame)                                │
├──────────────────────────────────────────────────────┤
│ 表单区（限宽 640px，左对齐，不居中）                    │
│                                                      │
│ 分组标题                                             │
│ ────────────────                                     │
│ 表单项                                               │
│                                                      │
│ 固定操作条（右下或底部通栏）                            │
└──────────────────────────────────────────────────────┘
```

### 规格
- Modal 表单：宽度 480 / 560 / 720 三档
- Modal 表单字段纵向排列，label 在上
- ⚠️ **Modal 里字段超过 6 个就别用 Modal** —— 改用独立页

## 十、L9 · 搜索结果 `SearchResults`

⚠️ **搜索区 + 结果区的组合** —— 论文库专用但值得统一。

```
┌──────────────────────────────────────────────────────┐
│ [🔍 关键词________________] [来源▾][年▾][OA▦] [检索] │
│ [已选条件：2020-2025 ×  Nature ×]              [重置] │
├──────────────────────────────────────────────────────┤
│ 共 128 篇 · 用时 340ms                    [导入][排序▾] │
├──────────────────────────────────────────────────────┤
│ 结果条目                                              │
└──────────────────────────────────────────────────────┘
```

### 规格
- 搜索框固定在顶部（滚动时不消失）
- 已选条件用可删除的 Chip 显示
- 结果计数 + 耗时
- 排序下拉在右侧
- ⚠️ **空结果和「没搜过」要区分** —— 一个说「没找到」，一个提示「输入关键词」

## 十一、L10 · 抽屉 `DetailDrawer`

```
┌────────────────────────┬────────────────────────────┐
│                        │ 详情标题              [×]  │
│                        ├────────────────────────────┤
│   原页面（变窄）        │ 内容                      │
│                        │                            │
│                        │ [操作区]                   │
└────────────────────────┴────────────────────────────┘
```

### 规格
| 项 | 规格 |
|---|---|
| 宽度 | 480 / 640 / 720 三档 |
| 遮罩 | **无**（不挡住原页面 —— 「不跳页」的关键）|
| ESC 关闭 | ✅ |
| 关闭后焦点 | 回到触发元素 |

⚠️ **无遮罩是刻意的** —— 有遮罩就变成了「弹窗」，用户感知是打断。

⚠️ **只用于「短任务」** —— 长表单、复杂确认不用它。

```
┌────────────────────────────────┐
│ 标题                       [×]  │
├────────────────────────────────┤
│ 内容                          │
│                                │
├────────────────────────────────┤
│              [取消]  [确定]     │
└────────────────────────────────┘
```

### 规格
- 三种类型：confirm / form / info
- confirm：按钮在右下，危险操作红色
- ⚠️ **删除确认必须带对象名**（"确定删除《Attention Is All You Need》？"）

## 十四、L13 · 状态视图 `StateView`

⚠️ **所有异步区统一用它** —— 现在主仓已有雏形（`QueryState`）。

```
加载中：
┌────────────────────┐
│ ▓▓▓▓▓▓▓░░░░░░░░░░  │
│ ▓▓▓▓▓▓▓░░░░░░░░░░  │
└────────────────────┘

出错：
┌────────────────────┐
│         ⚠          │
│      出错了          │
│   服务暂时不可用      │
│      [重试]         │
└────────────────────┘

空：
┌────────────────────┐
│         ⌀          │
│    还没有项目        │
│  从一篇论文开始…     │
│    [新建项目]       │
└────────────────────┘
```

### 规格
| 类型 | 组件 | 高度策略 |
|---|---|---|
| 加载 | Skeleton | 按内容估算行数 |
| 出错 | Result | 居中，有重试按钮 |
| 空 | Empty | 居中，有引导文案 + 行动按钮 |
| 无权限 | Result 403 | 居中 |

⚠️ **错误要显示真实原因** —— 不能只写「出错了」。

## 十五、L14 · 反馈层 `FeedbackLayer`

```
┌──────────────────────────────────────────────────────┐
│ [顶栏]                                                │
│                                        [🔔 通知]     │
│                                              ┌─────┐ │
│                                              │Toast│ │
│                                              └─────┘ │
│                                              [进度条] │
└──────────────────────────────────────────────────────┘
```

### 规格
- **Toast**：右下角堆叠，4 秒自动消失，悬停暂停
- **进度条**：顶栏下方通栏，**不遮挡内容**
- **通知中心**：顶栏铃铛，红点标记

⚠️ **长任务（渲染 PPT）用进度条，不要用 Toast** —— Toast 会消失，用户不知道进度。

## 十六、跨布局的一致性规则

### 间距刻度

⚠️ **只用 AntD 的 spacing token** —— 不要自定义 13px、18px 这种。

| 场景 | 值 |
|---|---|
| 图标与文字 | 4 / 8 |
| 控件之间 | 8 / 16 |
| 区块之间 | 16 / 24 |
| 页面区块之间 | 24 / 32 |

### 圆角
- 卡片：8
- 按钮/输入框：6
- 弹窗：12

### 阴影
- 卡片：极浅
- 弹窗/抽屉：中
- ⚠️ **不要在内容区用重阴影** —— 那是「浮起来」的意思

### 字体层级

| 层级 | 用途 | AntD |
|---|---|---|
| H1 | 页面标题 | Title level={2} |
| H2 | 区块标题 | Title level={4} |
| H3 | 卡片标题 | Title level={5} |
| 正文 | | Text |
| 辅助 | 元信息 | Text type="secondary" |
| 弱化 | 时间戳等 | Text type="secondary" + fontSize 12 |

⚠️ **字号只有 5 档** —— 不要随手加 15px、17px。

## 十七、哪些不进 ui 包（各站自己写）

| 东西 | 为什么 |
|---|---|
| **页面具体内容** | 论文卡片 vs 流程卡片，完全不同 |
| **业务专用的复合组件** | 如「论文卡片」「节点卡片」 |
| **特殊图表** | 如「时间线」「关系图」 |

⚠️ **判断标准**：
- **两个站都会用** → 进 ui 包
- **只有一个站用** → 留在那个站

## 十八、实施顺序建议

| 阶段 | 内容 | 理由 |
|---|---|---|
| **1** | L1 SiteShell + L2 PageFrame + L13 StateView | 每页都要用，先打好底 |
| **2** | L3 WorkspaceLayout + L10 Drawer + L9 SearchResults | 论文库要用 |
| **3** | L11 Modal + L14 Feedback + L12 CommandPalette | 通用交互 |
| **4** | L4 SplitLayout + L7 DocumentFlow | 详情/阅读类 |
| **5** | L5 Kanban + L6 Canvas | 状态/画布类（编排、演示）|
| **6** | L8 FormPage | 表单类 |

⚠️ **每阶段一个 commit**，每阶段结束各站都还能跑。
