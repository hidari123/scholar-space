## 决策演进脉络

```
ADR-0001  Polyrepo
   │
   ├── ADR-0011  规范以可执行配置承载
   ├── ADR-0012  脚手架以 TypeScript CLI 实现
   │
   ▼
ADR-0015  共享底座住主仓，发布到 GitHub Packages
   │
   ▼
ADR-0016  仓库结构 4+1+1 ──→ identity 独立成仓（用户要求可复用）
   │
   ▼
ADR-0017  管理员体系 ──→ 补上 nanobuddy 缺的两块（审计 + 身份不可伪造）
   │
   ▼
ADR-0018  G1 闸门评审 ──→ 规范真的能用吗？让独立仓跑一遍就知道
```

**贯穿主线**：**独立仓能独立复用** → 共享底座必须能被别人用 →
管理员身份不能靠网络隔离保证 → **规范必须被真实使用验证过**才算数。

## 模板

```markdown
# ADR-XXXX：标题

- **状态**：提议 / 已接受 / 已废弃 / 被 ADR-YYYY 取代
- **日期**：YYYY-MM-DD
- **决策者**：…

## 背景
为什么要做这个决策。有什么约束。

## 决策
决定了什么。

## 理由
为什么是这个方案，而不是备选。

## 备选方案
考虑过但没选的，以及为什么。

## 后果
### 正面
### 负面 / 代价
### 风险与缓解
```

## 决策原则

1. **可逆性优先**：容易撤销的决策轻量记录，难撤销的重记录
2. **记录理由而非结论**：半年后我们只记得"做了什么"，忘了"为什么"
3. **过期要更新**：约束变了要写新 ADR 标记取代，不要偷偷改
4. **不记录实现细节**：那是代码和文档的事
