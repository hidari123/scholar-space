# gateway

scholarspace API 网关 —— **唯一对外入口**。

## 职责

| 职责 | 说明 |
|---|---|
| **路由映射** | 旧路径 → 新路径 |
| **特性开关** | 按路径前缀控制走新还是旧 |
| **反向代理** | 转发到各独立服务 |

## ⚠️ 网关不合并服务

各服务是**独立部署**的（独立仓），
网关通过 HTTP 反向代理转发，**不 import 它们的代码**。

⚠️ **这样各服务才能独立发布** —— 改 PPT 不需要重启社区服务。

## 切流机制

```yaml
# config/routing.yaml
routes:
  /api/v2/social/statuses | /api/v1/community/statuses | community | community.statuses
```

⚠️ **四个字段**：`旧路径 | 新路径 | 目标服务 | 特性开关`

⚠️ **开关留空 = 无条件切换**（已经切完了）

⚠️ **顺序很重要** —— 第一个命中的赢。
具体路径要排在通配符前面。

## ⚠️ 开关默认关闭

新服务刚上线时开关是关的，**出问题能立刻关掉**。

⚠️ **不存在的开关一律返回 False** ——
「未知 = 关闭」比「未知 = 开启」安全。
